表現・インタラクションのアイデアExpression and interaction ideas

本命は『Coarse First Arrival Field』。pointer を視点 priority、click/Space をストリーム到着に見立て、粗いセルから細かな splat へ解像する波を描く。派生『Mesh Blend Afterimage』は pointer を blend plane、click を境界の保持として、二つの SDF 形状の seam を残像へ変える。短期では音の onset を arrival burst、スクロール速度を LOD 密度、映像の optical flow を blend plane へ接続する。中長期では WebXR gaze を priority、実 GSplat の LOD event と GPU frame time を、光・粒子・文字に共通な quality score として再配分する。

Map attention to priority and events to arrival or retained seams; later feed real LOD and frame-time telemetry into the same score.

制作に使えそうな技術メモProduction notes

まず coarse asset を単独で意味のある silhouette / 色面にする。LOD event は `requestedAt`, `arrivedAt`, `level`, `cameraDistance`, `gpuFrameMs` を記録し、読み込み比率だけでなく“観客に見えた時刻”を評価する。blend は alpha の穴ではなく signed distance または depth/normal 差から seam mask を作ると、境界だけを発光・音・粒子に送れる。WebGL fallback は 1 枚の full-screen fragment shader か、小さな ping-pong FBO のみに留める。Inspector の計測値は必ず実測値として表示し、演出用の推定 quality と混ぜない。

Make the coarse state meaningful, log perceptual arrival separately, derive seams from distance/depth/normal, and keep WebGL fallbacks small.

俯瞰メモBird's-eye memo

10月後半から、compile・shadow・LOD・visibility・history・environment・radiosity を『準備→到着→残響』として扱ってきた。今日の核は、品質を単なる最適化結果でなく、観客へ情報が届く順番として設計することにある。`gaze + audio onset + lod arrival + seam age + gpuFrameMs` を共通 score にすれば、GSplat、反射、文字、粒子、空、照明の時間を同期できる。特に “粗いものが先に意味を持つ” 設計はモバイル・XR・展示のすべてで育てる価値が高い。

The durable theme is a shared score for preparation, arrival and afterglow across rendering systems; meaningful coarse states are especially valuable.
