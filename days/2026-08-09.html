注目事例と何が面白いかNotable example and why it matters

今日いちばん面白いのは Babylon.js PR #18774。Gaussian Splatting の streaming LOD を別 mesh / 別 worker / 別 draw call として扱うのではなく、compound mesh の atlas 内に row-aligned reserved region として住まわせる設計になっている。表現面では、スプラットがただ増減するのではなく、「空いている帯へ流れ込む」「tombstone で穴が残る」「compactAtlas() で記憶が詰め直される」という時間構造をそのまま可視化できる。Codrops の Wave Grid が mouse trail texture で波を伝播させたように、ここでは shared atlas の帯を波・地層・記憶領域として扱える。

The strongest item today is Babylon.js PR #18774. Instead of treating Gaussian Splatting streaming LOD as a separate mesh, worker, and draw call, it hosts the stream inside a compound mesh atlas as a row-aligned reserved region. Expressively, splats do not merely appear and disappear: they flow into reserved bands, leave tombstone gaps, and get re-packed by `compactAtlas()`. Like Codrops' Wave Grid propagates waves through a mouse-trail texture, a shared atlas can become a wave field, sediment layer, or memory region.

制作に使えそうな技術メモProduction note

Gaussian Splatting の streaming は、見た目の LOD だけでなく memory layout の設計問題として扱うと強い。shared atlas を使うなら、row reservation、active LOD range、tombstone、compaction、GPU defrag を debug overlay ではなく演出パラメータにできる。three.js の backdrop blur 最適化からは、postprocess は品質を一律に上げるより repeats / radius / sample direction を interaction に応じて変えた方がよい、という示唆がある。DepthOfFieldNode の render target leak fix も含め、ポスト処理は見た目の気持ちよさと resource lifetime が近い。GPU particle gradient LUT は、色変化を uniform 配列で押すより texture update として扱うと、音反応や状態遷移を「焼き直される色帯」として見せやすい。

Gaussian Splatting streaming becomes stronger when treated as memory layout, not only visual LOD. With a shared atlas, row reservation, active LOD ranges, tombstones, compaction, and GPU defrag can become expressive parameters instead of just debug overlays. The three.js backdrop blur optimization suggests that postprocessing should vary repeats, radius, and sample direction by interaction instead of uniformly increasing quality. The DepthOfFieldNode render target leak fix reinforces that postprocess aesthetics and resource lifetime sit close together. GPU particle gradient LUTs are also useful as texture updates: audio reaction or state transitions can become color bands being rebaked.

Today's sample uses pointer, mode, pressure, and time as inputs, with atlas bands, chunk density, tombstone lines, blur lenses, and gradient particles as render states. As data, it can record which band users bend, which chunks ignite under pressure, and how far a low blur-repeat count can be used expressively.
