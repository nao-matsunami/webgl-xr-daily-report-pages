It cites roughly 30-35 FPS for blur and 60 FPS for checker on tested Mac mini M2 Pro and Pixel 8a devices, making 'show the budget' more compelling than 'blur everything'. 2. Babylon.js PR #18774 was merged on 2026-08-09 UTC. It is another case of moving data that cannot fit comfortably in uniforms into texture lanes, similar to SOG atlases. 4. three.js PR #33286 continues native equirect / quad media layer rendering for XR. Together with Babylon WebGPU XR quad layers, video, panoramic media, and UI planes are moving toward separate layers. 5. PlayCanvas #9156 and #9151 continue to matter as topology and API surfaces become inputs for both people and generated code.

The most expressive item today is three.js PR #34195. Choosing a checker effect instead of a beautiful blur is useful as a design move: expose the constraint and turn it into style. Rather than reducing blur samples and making the result look degraded, make checker, dither, and quantized cells intentional from the start. On Codrops, the 2026-08-07 PX PUSH article frames a website around an old, always-on machine running underneath a modern Nuxt / Three.js stack. 表現・インタラクションのアイデアExpression and interaction ideas

短期案は「Checker Budget Atlas Scope」。画面を checker cell の集合として扱い、pointer 付近だけ dither / checker の density を変える。昨日の SOG atlas band はそのまま mode 3 に残し、mode 1 で blur budget を checker に置換、mode 2 で bone texture fallback を骨格線として、mode 4 で XR equirect / quad media layer を円形レイヤーとして描く。ドラッグで cell の曲がり、クリック/Space で stream pressure を入れる。中長期では、この checker cell を実フレーム時間、postprocess sample count、SOG chunk residency、XR layer count、bone texture upload 量へ接続する。

The short-term idea is Checker Budget Atlas Scope. Treat the screen as checker cells and change dither / checker density around the pointer. Yesterday's SOG atlas bands remain as mode 3; mode 1 replaces blur budget with checkers, mode 2 renders bone texture fallback as skeletal lines, and mode 4 turns XR equirect / quad media layers into circular layer fields. Drag bends cells, and click or Space injects stream pressure. Longer term, map these cells to real frame time, postprocess sample count, SOG chunk residency, XR layer count, and bone texture upload volume.

制作に使えそうな技術メモProduction notes

blur は高級感を出しやすいが、WebGPU example 全体の中で最重になるなら、表現の前提を変えた方がよい。checker / ordered dither / Bayer matrix / low-res cell は、サンプル数削減を画質低下ではなく「量子化された現実」として見せられる。SkinningNode の bone texture fallback からは、uniform limit にぶつかる状態を texture atlas として解く発想を得られる。SOG atlas、bone texture、gradient LUT、media layer は別機能に見えるが、実装上は「連続値や構造を GPU が読みやすい面へ詰める」点で共通している。PlayCanvas の triangle strip から indexed triangles への修正も、見た目の乱れが topology の選択から来ることを示しており、debug overlay ではなく演出上の破綻線として扱える。

Blur easily creates polish, but if it becomes the heaviest WebGPU example, changing the expressive premise is better. Checker, ordered dither, Bayer matrices, and low-resolution cells can make sample reduction feel like quantized reality instead of degraded quality. The SkinningNode bone texture fallback suggests solving uniform limits by moving structured data into texture atlases. SOG atlases, bone textures, gradient LUTs, and media layers look like separate features, but all pack continuous values or structures into GPU-readable surfaces. PlayCanvas' move from triangle strips to indexed triangles also shows how visual artifacts can come from topology choices; those artifacts can become intentional fault lines.

俯瞰メモBird's-eye memo

最近の傾向は、豪華なエフェクトを増やすより、実装上の制約を見た目の文法へ変える方向が強い。8/8 は resource lifetime、8/9 は shared atlas / blur budget、今日は checker budget / bone texture fallback。どれも、GPU が内部で抱えている面・帯・寿命・上限を可視化する線上にある。組み合わせ候補は、SOG chunk の residency を checker cell に、bone texture fallback を骨格線に、XR media layer を円形 lens に、Web Audio を pressure pulse に割り当てる構成。育てる価値が高いテーマは「budget as texture」。性能予算を非表示の制約ではなく、作品が呼吸する粒度・格子・明滅として扱う。

The recent trend is not adding richer effects, but turning implementation constraints into visual grammar. 8/8 focused on resource lifetime, 8/9 on shared atlas / blur budget, and today on checker budget / bone texture fallback. All visualize GPU surfaces, bands, lifetimes, and limits. A promising combination maps SOG chunk residency to checker cells, bone texture fallback to skeletal lines, XR media layers to circular lenses, and Web Audio to pressure pulses. The high-value theme is budget as texture: performance budget becomes grain, grid, and flicker that the artwork breathes through.

サンプルデータの可能性と組み合わせ考察Possibilities for the sample data and combinations

今日のサンプルは pointer、mode、pressure、time を入力にし、checker cell、dither lens、skeletal line、atlas band、media layer ring を描画状態として持つ。データとして見ると、ユーザーがどの cell 密度を触ったか、pressure 時にどの atlas band が発火したか、checker と blur の代替がどの程度視覚的に成立するかを記録できる。展示やライブ演出では、音の低域で cell を粗く、中域で atlas band を開閉し、高域で dither lens を明滅させると扱いやすい。WebXR では equirect layer を背景、quad layer を手元 UI、SOG atlas を空間の記憶帯として配置できる。ブランド演出では、loading や fallback を隠すのではなく、常時動く機械のような checker budget として見せると、性能制約が世界観になる。

Today's sample uses pointer, mode, pressure, and time as inputs, with checker cells, dither lenses, skeletal lines, atlas bands, and media-layer rings as render states. As data, it can record which cell density users touched, which atlas bands fired under pressure, and whether checker can replace blur convincingly. For installations or live visuals, map bass to coarser cells, mids to atlas band gates, and highs to dither lens flicker. In WebXR, use an equirect layer as background, a quad layer as hand UI, and SOG atlas bands as spatial memory strips.
