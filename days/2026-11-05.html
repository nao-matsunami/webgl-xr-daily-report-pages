表現・インタラクションのアイデアExpression and interaction ideas

本命『Timestamp Radiance Score』は pointer を inspection light、click/Space を GPU pass marker として、direct→bounce→composite の到着を同じ画面で見せる。派生『Dynamic Attribute Afterglow』は属性 upload を光の筆跡へ変える。短期では Web Audio の onset を marker、スクロールや pointer velocity を dynamic attribute の更新量にする。中長期では `passStart/passEnd`, `queryAvailable`, `compileReady`, `uploadBytes`, `lodArrivedAt` を共通 state texture に記録し、計測の遅延そのものを影・粒子・文字の密度にする。

Map real completion and upload signals to light, afterglow and density; start with audio onset or pointer velocity, then wire telemetry into a shared state texture.

制作に使えそうな技術メモProduction notes

timestamp query は availability を確認してから読み、CPU 時刻と混同しない。render pass が再開・分割される構成では `passId`, `layer`, `begin`, `end`, `queryAvailable` を一組で保存する。dynamic attributes は毎フレーム丸ごと更新せず、dirty range と `uploadBytes` を取り、更新された頂点だけを発光させると意味が生まれる。MRT は色、輝度、motion／history を分け、clear color も出力ごとに意図を持たせる。WebGL fallback は今回のような full-screen fragment shader にして、実測が取れない環境では『推定』と明記する。

Keep timestamp availability distinct from CPU time; log pass identity and dirty ranges; use MRT outputs with intentional clears, and label fallback signals as estimates.

俯瞰メモBird's-eye memo

10月後半から compile、shadow、LOD、history、reflection、radiosity を『準備→到着→残響』として扱ってきた。今日加えるべきなのは到着の正確な時計だ。`gaze + audio onset + pass duration + query availability + upload bytes + lod arrival + seam age` を共通 score にすると、実装上の変化と観客の注視を同じテンポで編集できる。計測を可視化するのではなく、計測が起きた瞬間だけ世界が少し変わる設計は、展示・ライブ演出・プロダクトの opening まで育てる価値が高い。

The durable next step is a shared clock: performance events should subtly alter the world, not merely appear as diagnostics.
