制作に使えそうな技術メモProduction notes

TAA/SVGF系の見た目を作るときは、jitter offset、history weight、reset mask、disocclusion threshold、resolutionScaleをUIではなく演出パラメータとして持つと扱いやすい。ASCII化は文字を本当にDOMで並べるより、まずshader内でセルと線分/円弧に量子化すると軽い検証ができる。Babylon.js #18880の示唆は、WebGPU bind groupやUBO poolの増加を「draw orderの揺れ」としてログ化すること。安定slot化の前後を色分けすると、メモリリーク調査だけでなく、同じobjectがGPU上で同じ場所へ戻ってくる安心感を表現にできる。PlayCanvas #9300/#9305からは、physics pause、manual step、collision group/mask、raycastAll sort有無を、展示用の時間停止/手動スキャン/選択レーンに転用できる。

For TAA/SVGF-style looks, treat jitter offset, history weight, reset masks, disocclusion thresholds, and resolutionScale as expressive parameters rather than only UI settings. For ASCII conversion, first quantize cells and strokes in the shader instead of building DOM characters; it is faster for small tests. Babylon.js #18880 suggests logging bind-group or UBO-pool growth as draw-order instability. Coloring before/after stable slot assignment turns memory investigation into a visible sense that each object returns to the same GPU location. PlayCanvas #9300/#9305 suggest reusing physics pause, manual step, collision groups/masks, and optional raycastAll sorting as time-freeze, manual scan, and selection-lane controls.

サンプルデータの可能性と組み合わせ考察Possibilities for the sample data and combinations

今日の2本は、入力値と描画状態をデータとして持つと発展しやすい。1本目は jitter center、history reset pulse、ASCII threshold、denoise strength、blue-noise seedをログ化できる。2本目は owner id、slot index、draw order drift、physics timeScale、manual step count、raycast group/mask/hitを持てる。Web Audioなら低域でhistory weight、中域でASCII threshold、高域でblue-noise seedを動かす。MediaPipeなら手の開閉をreset mask、手速度をjitter量へ送る。WebXRなら注視object IDをowner slotに固定し、床/壁/展示物だけraycast対象にする。ブランド演出では、ロゴが時間蓄積で読めるようになり、安定したobjectだけが選択できるため、読みやすさそのものをインタラクション条件にできる。

The two samples can grow if their inputs and render state are treated as data. The first can log jitter center, history reset pulse, ASCII threshold, denoise strength, and blue-noise seed. The second can hold owner ID, slot index, draw-order drift, physics timeScale, manual step count, and raycast group/mask/hit. With Web Audio, bass can drive history weight, mids ASCII threshold, and highs blue-noise seed. With MediaPipe, hand open/close can drive reset masks and hand speed can drive jitter amount. With WebXR, gaze object IDs can be fixed to owner slots while only floor/wall/exhibit objects are raycast targets. In brand work, a logo becomes readable through temporal accumulation and only stable objects become selectable, so readability itself becomes an interaction condition.
