注目事例と何が面白いかNotable examples and why they matter

今日の面白さは、安定化・互換性・ローダー修正が全部「待っている状態の見せ方」に変換できる点。three.js の HTTP Range requests と transmission / refraction 系は、透明な空間の一部だけが先に届き、深度で守られながら解像する演出にできる。PlayCanvas の coarsest-first GSplat は、粗い点群が全体像を先に置き、視線近くのみ細かくなる。Babylon の color-space / draw wrapper cache / interactivity export は、passごとの記憶や入力イベントを色帯として見せる入口になる。Codrops の Datamosh や Glass Xylophone は、破綻・音・遷移を隠さず素材化する良い参照。

The interesting thread today is that stabilization, compatibility, and loader fixes all translate into ways of showing a waiting state. three.js HTTP Range requests plus transmission / refraction work suggest transparent spaces where only selected byte windows arrive first and resolve under a depth guard. PlayCanvas coarsest-first GSplat places a rough point-cloud overview first, then refines near gaze. Babylon color-space, draw-wrapper cache, and interactivity export provide entry points for showing per-pass memory and input events as color bands. Codrops Datamosh and Glass Xylophone are useful references because they turn breakage, sound, and transitions into material rather than hiding them.

制作に使えそうな技術メモProduction notes

ログ化候補は `rangeStart/rangeEnd/rangePriority/requestBurst/transmissionPassId/refractionGuardDepth/depthRejectCount/coarseFirstRank/lodLevel/splatBudget/canvasClientZero/canvasResolutionKept/miniStatsVisible/miniStatsSkipped/textureRetryCount/cacheHit/drawWrapperPass/canvasColorSpace/renderTargetSRGB/viewportScale/scissorRect`。実装は 16x16 か 32x8 の state texture に、chunk到着、LOD、guard、retryを詰め、fragment shader 側で lane / ring / caustic / tile に変換するのが軽い。three.js 側は FileLoader Range と transmission/refraction、PlayCanvas 側は GSplat LOD と canvas/MiniStats、Babylon 側は color-space と pass cache を入口にする。

Candidate log fields include `rangeStart/rangeEnd/rangePriority/requestBurst/transmissionPassId/refractionGuardDepth/depthRejectCount/coarseFirstRank/lodLevel/splatBudget/canvasClientZero/canvasResolutionKept/miniStatsVisible/miniStatsSkipped/textureRetryCount/cacheHit/drawWrapperPass/canvasColorSpace/renderTargetSRGB/viewportScale/scissorRect`. A lightweight implementation packs chunk arrival, LOD, guard, and retry values into a 16x16 or 32x8 state texture, then converts them in the fragment shader into lanes, rings, caustics, and tiles. Use three.js FileLoader Range plus transmission/refraction, PlayCanvas GSplat LOD plus canvas/MiniStats, and Babylon color-space plus pass cache as the entry points.
