制作に使えそうな技術メモProduction notes

shadow cascade は split circle / lane / picked shader variant を分けると、単なる影品質設定ではなく視点距離の譜面になる。StandardMaterial の texture map iteration は、own property と prototype property を色分けすると、継承されたmaterial kitの見落としを視覚的に検出できる。TSL `.toInspector()` は texture nodeだけでなく scalar / vector / Fn result まで表示対象にできると、shader authoring 中の「見えない中間値」を演出へ回しやすい。cache key はhash値そのものを出すより、cache hit / miss / rebuild pulse / node depth に分解したほうがパフォーマンス診断と美術が両立する。WebGL1互換の最小試作では、fwidthやWebGL2前提を避け、line / ring / box SDF と procedural noise だけで十分な状態表現を作るのが扱いやすい。

Shadow cascades become a viewpoint-distance score when split circles, lanes, and picked shader variants are separated visually. StandardMaterial texture-map iteration can color own properties and prototype properties differently, making missed inherited material kits visible. If TSL `.toInspector()` covers scalar, vector, and Fn results in addition to texture nodes, otherwise invisible intermediate shader values become expressive inputs. Cache keys work better as cache hit / miss / rebuild pulse / node depth than as raw hashes, balancing performance diagnosis and art direction. For a WebGL1-compatible minimum prototype, avoid fwidth and WebGL2 assumptions; line / ring / box SDFs and procedural noise are enough to draw rich state surfaces.
