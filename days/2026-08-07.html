注目事例と何が面白いかNotable examples and why they matter

今日一番面白いのは、PlayCanvas PR #9155 の「hidden なのに見えている」問題。XR session 外で XrMenu が world origin に残るのは単なるバグだが、表現として見ると、内部状態、scene graph、opacity、session active の4層が同期していない瞬間が可視化されている。これを制作に転用すると、UI や 3D オブジェクトが「本来見えないが、状態不一致のときだけ幽霊のように現れる」演出になる。Codrops の Cerebrium がインフラ構造を触れる空間にしたように、render engine の hidden state も作品の素材になる。

The most interesting case today is PlayCanvas PR #9155's hidden-but-visible problem. An XrMenu remaining at world origin outside an XR session is a bug, but as an expression it reveals a moment where internal state, scene graph, opacity, and session activity are out of sync. Reused deliberately, UI or 3D objects can appear like ghosts only when state mismatches occur. Just as Codrops' Cerebrium turns infrastructure into a tangible space, render engine hidden state can become raw material for an experience.

表現・インタラクションのアイデアExpression and interaction ideas

短期案は「Capability Layer Prism」。XR per-eye clear、transmission layerMask、RawCubeTexture guard、XR menu hidden state を4つの可視レーンにする。1 は左右眼 clear と half-Z NDC、2 は透明面の layerMask と inspection lens、3 は cube reflection の invertY crash guard、4 は XR session 外に残る menu ghost と immediate hide を強調する。ドラッグは layer mask のずれ、クリック/Space は hidden-state pressure。中長期では、この疑似レーンを Babylon WebGPU-XR ログ、three.js WebGPU refresh type、PlayCanvas XrMenu state、実透明パスの layerMask に差し替える。

The short-term idea is Capability Layer Prism. It turns XR per-eye clear, transmission layerMask, RawCubeTexture guard, and XR menu hidden state into four visible lanes. Key 1 emphasizes left/right-eye clear and half-Z NDC, 2 the transparent surface layerMask and inspection lens, 3 cube reflection invertY crash guard, and 4 the menu ghost outside XR sessions plus immediate hide. Dragging shears the layer mask, and click or Space adds hidden-state pressure. Longer term, replace the synthetic lanes with Babylon WebGPU-XR logs, three.js WebGPU refresh types, PlayCanvas XrMenu state, and real layer masks from a transparent render pass.

制作に使えそうな技術メモProduction notes

XR や透明表現では、capability と visibility を別チャンネルで持つのがよい。Raw Camera Access のように WebGPU-XR で明示的に無効化されるものは、単に feature unavailable と出すだけでなく、画面上の guard lane にする。transmission opaque texture の camera layerMask は、透明面が何を透過対象にしているかを mask texture として見せるとデバッグと演出が兼ねられる。three.js の render object refresh type は、フル refresh、shared UBO refresh、per-object refresh を色分けすると WebGPU の更新粒度を説明しやすい。PlayCanvas XrMenu のような session 外 UI は、container enabled、element opacity、target opacity、xr.active を同時にログ化すると、見た目と状態のズレを検出できる。

For XR and transparent rendering, keep capability and visibility as separate channels. Features explicitly disabled in WebGPU-XR, such as Raw Camera Access, should become on-screen guard lanes rather than only feature-unavailable messages. The camera layerMask for transmission opaque textures can be displayed as a mask texture, serving both debugging and expression. three.js render object refresh types become easier to explain when full refresh, shared UBO refresh, and per-object refresh are color-coded. For session-bound UI such as PlayCanvas XrMenu, logging container enabled, element opacity, target opacity, and xr.active together exposes mismatches between visual output and state.

Yesterday's ref/event scope covered the boundary between asset and interaction; today's capability prism covers the boundary between session and visibility. サンプルデータの可能性と組み合わせ考察Possibilities for the sample data and combinations

今日のサンプルは pointer、velocity、pressure、mode を入力にし、XR clear、transparent mask、cube guard、menu ghost を描画状態として持つ。これをデータとして見ると、ユーザーがどの capability 境界を検査したか、どこで hidden-state pressure が高まったか、mask がどの方向にずれたかを時系列で扱える。音と組み合わせるなら、低域で hidden pressure、中域で layerMask shear、高域で RawCube guard を点滅させる。画像や video texture と組み合わせるなら、透明面の mask 内だけ映像を透過させ、guard lane が立つと映像が遮断される。WebXR と組み合わせるなら、実 session start/end、feature availability、controller hover を同じ prism に流せる。展示やブランド演出では、通常は見えない品質保証や互換性の層を、製品の信頼性や精密さを表す発光構造として見せられる。

Today's sample uses pointer, velocity, pressure, and mode as inputs, with XR clear, transparent mask, cube guard, and menu ghost as render state. As data, it can track which capability boundary the user inspected, where hidden-state pressure increased, and how the mask shifted over time. With audio, bass can drive hidden pressure, mids layerMask shear, and highs RawCube guard flicker. With image or video textures, the transparent mask can reveal video only inside its region, while guard lanes cut it off. With WebXR, real session start/end, feature availability, and controller hover can feed the same prism. In installations or brand experiences, invisible QA and compatibility layers can appear as luminous structures that communicate precision and reliability.
