注目事例と何が面白いかNotable examples and why they matter

注目は PlayCanvas の MSDF 修正を、単なるテキスト品質ではなく splat 上の注釈・ラベル・測定値の信頼性として見る点。relighting docs の coverage alpha は、どのピクセルが proxy mesh の照明を受けているかを示せるため、文字の縁取り品質、splat の照明適用範囲、sorting の不確かさを同じ overlay に載せられる。Babylon の MediaStream/WebRTC spatialize 修正は、Web Audio 系の作品で「音源がどこにあるか」を renderer とは別の DOM 表示で説明せず、音波リングや方向ベクトルとして空間内に出す発想につながる。three.js の volumetric fire / custom fog は、品質診断の色を煙や炎の層へ溶かす参考になる。

The interesting angle is reading the PlayCanvas MSDF fix not just as text quality, but as reliability for labels, annotations, and measurements drawn over splats. Relighting coverage alpha can indicate which pixels receive proxy-mesh lighting, so edge quality, lighting coverage, and sorting uncertainty can share one overlay. Babylon's MediaStream/WebRTC spatial audio fix points toward showing live sound source positions as wave rings or direction vectors in the scene instead of explaining them through separate DOM UI. three.js volumetric fire and custom fog are useful references for dissolving diagnostic color into smoke and fire-like layers.

For a short-term test, build an MSDF edge halo plus spatial audio vectors. Sound can use a synthetic beat rather than real input, with rings arriving from multiple source directions. Longer term, map each WebRTC participant MediaStream to a point sound source in a splat space and visualize speech, position, relighting coverage, and annotation readability together. This extends yesterday's fisheye tile bias field by layering text and audio pressure over projection pressure.

制作に使えそうな技術メモProduction notes

MSDF は小サイズ、mipmap、色空間、post bloom の順で縁の破綻が目立つ。splat viewer 内のラベルは通常の DOM より背景の粒状ノイズを受けやすいので、edge distance、halo distance、coverage mask を別チャンネルで持つと調整しやすい。PlayCanvas relighting は offscreen texture の alpha を coverage として使うので、未カバー領域の注釈は自動で補色・太字・背景光を変えられる。Babylon AudioV2 の MediaStream/WebRTC spatialize は、実装上は音声 stream の lifetime と scene node の lifetime を揃える必要がある。three.js / TSL 側で将来置き換えるなら、音源方向、coverage、text edge を node material の debug output として切り替える設計がよい。

MSDF failures tend to surface around small sizes, mipmaps, color space, and bloom. Labels inside splat viewers receive more granular background noise than ordinary DOM text, so keeping edge distance, halo distance, and coverage mask as separate channels makes tuning easier. PlayCanvas relighting uses offscreen texture alpha as coverage, which can drive annotation contrast, weight, or backlight in uncovered regions. With Babylon AudioV2 MediaStream/WebRTC spatialization, sound stream lifetime and scene node lifetime should be managed together. If this moves to three.js/TSL later, sound direction, coverage, and text edge state should be switchable as node-material debug outputs.
