制作に使えそうな技術メモProduction notes

three.js側はr187移行時にrender target bind中のsetViewport/setScissorを再確認する。過去コードでdevicePixelRatioを二重に掛けていると、postprocessやmini viewportの切り出しがずれる可能性がある。PMREMはcube render targetベースになるので、reflectionの見た目差をA/Bできるようにcaptureを残す。Babylon側はalpha sourceごとのdepth pre-passとalphaCutOffのbinding、OBJ texture wait、Gaussian Splatting data texture nearest samplingを見る。PlayCanvas側はmaterialなしmeshのlayer受付、SOG/gsplat LOD、depth picking、GPU sort precisionを同じログ項目で追う。

For three.js, audit setViewport/setScissor when a render target is bound during r187 migration. Code that double-applies devicePixelRatio can misalign post effects or mini viewport crops. Since PMREM is cube-render-target based, keep A/B captures of reflection differences. For Babylon, watch alpha-source depth pre-pass behavior, alphaCutOff binding, OBJ texture waits, and nearest sampling for Gaussian Splatting data textures. For PlayCanvas, track material-less mesh layer acceptance, SOG/gsplat LOD, depth picking, and GPU sort precision in the same log schema.

The theme worth growing is not a debug HUD, but renderer-state theater that can stand as an artwork.

サンプルデータの可能性と組み合わせ考察Possibilities for the sample data and combinations

今回の2本は、入力値を `probeX/probeY/pulse/mode`、描画状態を `viewportScale/scissorRect/pmremFace/textureAge/finalizedAtFrame/materialReady/alphaCutOff/rootMotionDelta` として保存できる。音反応ならkickでresize pulse、hatでalpha lane、低域でPMREM faceの明度を揺らす。WebXRなら左右eyeのprojection/scissor差を可視化し、MediaPipeなら顔や手のlandmarkをscissor probeにする。展示では、来場者の移動がroot motion traceになり、透明な幕やgridが描画状態の変化として開閉する構成が合う。

These two samples can store inputs as `probeX/probeY/pulse/mode` and render state as `viewportScale/scissorRect/pmremFace/textureAge/finalizedAtFrame/materialReady/alphaCutOff/rootMotionDelta`. For audio, kick can drive resize pulses, hi-hats can drive alpha lanes, and bass can modulate PMREM face brightness. For WebXR, visualize projection/scissor differences between eyes; for MediaPipe, map face or hand landmarks to the scissor probe. In an installation, visitor movement can become root-motion traces while translucent curtains or grids open and close as render-state changes.
