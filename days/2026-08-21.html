注目事例と何が面白いかNotable example and why it matters

今日の注目は three.js #34319 と Codrops Run Rob Run の組み合わせ。volumetric fog は通常、低解像度で計算してぼかして戻す「見えない最適化」になりやすいが、JBU のように depth / normal / edge を頼りに戻すと、境界だけが残る霧、音のピーク時だけ粗さが見える霧、スクロール速度で upsample kernel が変わる霧にできる。Run Rob Run の goo は、音の解析値を形状変形と damping に入れているので、fog resolve の kernel radius や temporal accumulation の重みと相性が良い。つまり、音で揺れる物体を照らすだけでなく、音で「低解像度バッファの戻し方」が変わる。

The notable combination is three.js #34319 with Codrops' Run Rob Run. Volumetric fog often becomes an invisible optimization: render low-resolution, blur, then resolve. With JBU-style depth / normal / edge guidance, the resolve itself can become expressive: fog that keeps only boundaries, fog whose coarse cells appear on audio peaks, or fog whose upsample kernel changes with scroll velocity. Run Rob Run feeds audio analysis into deformation and damping, which maps naturally to fog kernel radius or temporal accumulation weight. The object is not merely lit by audio; audio changes how the low-resolution buffer returns to the final image.

制作に使えそうな技術メモProduction note

JBU / edge-aware upsampling の最小要素は、低解像度 buffer、guide になる depth/normal、空間距離 weight、guide 差分 weight の4つ。three.js #34319 の示唆は、fog を高解像度で全部計算するのではなく、低解像度で作って edge-aware に戻すこと。Babylon.js #18815 の示唆は、半透明 splat の影を binary occupancy で固定しないこと。opacity を voxel に残し、sample 時に roulette する発想は、fog density、particle trail、audio grain にも転用できる。PlayCanvas #9198 の phantom sampler は、shader reflection / bind group layout の QA 表現として面白い。末尾 texture だけ余分な sampler が付くようなバグは、画面上では「存在しない resource slot が点滅する」演出に変換できる。PlayCanvas #9197 の AABB culling は、sphere で膨らんだ見えない領域を削る話なので、長い beam / ribbon / fog slab の可視化に効く。

The minimum ingredients for JBU / edge-aware upsampling are a low-resolution buffer, depth/normal as a guide, spatial-distance weight, and guide-difference weight. three.js #34319 suggests not calculating all fog at full resolution, but producing low-resolution fog and resolving it edge-aware. Babylon.js #18815 suggests not freezing transparent splat shadows as binary occupancy: storing opacity in voxels and applying roulette at sample time can also apply to fog density, particle trails, and audio grains. PlayCanvas #9198's phantom sampler is useful as shader reflection / bind-group-layout QA expression; a bug where only the trailing texture gets an extra sampler can become a flashing nonexistent resource slot. PlayCanvas #9197's AABB culling removes invisible volume inflated by sphere bounds, which matters for long beams, ribbons, and fog slabs.

サンプルデータの可能性と組み合わせ考察Possibilities for the sample data and combinations

今日のサンプルは、pointer、impulse、procedural depth、fog density、edge weight、low-res cell id、phantom sampler flag をデータとして扱える。展示では、来場者の手や声で霧の解像度と復元半径が変わる壁面にできる。Web演出では、製品写真やライブ映像を depth guide として使い、通常時は綺麗な fog resolve、操作時だけ低解像度 grid と resource slot が露出する表現にできる。MediaPipe と組み合わせるなら、手の速度を impulse、顔の向きを light、口の開きや声量を fog density に割り当てる。WebXR では、quad layer 上の billboard を edge-aware fog で覆い、背後の GSplat hit distance や IBL shadow opacity を guide に混ぜると、2D面・splat・空間照明の境界が曖昧になる。NixieFX 的な authored particle を入力にすると、粒子を一度 fog buffer に溶かし、JBU で輪郭だけ戻すような演出が作れる。

Today's sample can treat pointer, impulse, procedural depth, fog density, edge weight, low-res cell id, and phantom sampler flag as data. In an installation, hand movement or voice can change fog resolution and reconstruction radius on a wall. On the web, product photos or live video can act as depth guides: normally a clean fog resolve, while interaction exposes the low-resolution grid and resource slots. With MediaPipe, hand speed can drive impulse, face direction can drive light, and mouth opening or voice level can drive fog density. With authored particles like NixieFX, particles can dissolve into a fog buffer and return only at their guided edges through JBU.
