注目事例と何が面白いかNotable examples and why they matter

three.js r186 の native Gaussian splat は、7月以降このプロジェクトで追ってきた SOG / splat / LOD / raycast を、外部ビューワの題材から three.js 本体の表現素材へ近づけた点が大きい。PlayCanvas の empty LOD 修正は地味だが、空レベルを「壊れ」ではなく「どの階層がまだ届いていないか」として演出化する入口になる。Babylon の USD loader は、OpenUSDをWebAssembly + Workerで動かし、stage composition と command queue を分離するので、9/6 の USD worker stage scan を実データへ寄せやすい。Codrops側では 3D Face Mask / Unwoven / ASCII / Datamosh が、身体、織り、文字、履歴という4つの入力を同じshader状態へ混ぜる実例群として効いている。

three.js r186 matters because native Gaussian splats move the SOG / splat / LOD / raycast thread followed here since July from external viewer material toward core three.js expression material. PlayCanvas' empty LOD fix is subtle, but it makes empty levels readable as 'which level has not arrived yet' instead of mere breakage. Babylon's USD loader runs OpenUSD through WebAssembly and a Worker, separating stage composition from the command queue, so September 6's USD worker stage scan can move closer to real data. On the Codrops side, 3D Face Mask, Unwoven, ASCII, and Datamosh provide a compact set of body, weave, glyph, and history inputs for shader state.

制作に使えそうな技術メモProduction notes

SplatのLOD欠落は、alphaを落として消すだけだと不具合に見える。空レベルを別色のgap maskにし、frustumやraycast線と同期させると「まだ届いていない情報」として読める。object ID texture は選択輪郭だけでなく、色相、線密度、stream age のindexとして使うと診断と美術が重なる。USD loader は worker queue、command queue、data buffer、materialization の4段階に分けると、長いロードを退屈なprogress barではなく時間構造にできる。three.js r186/r187系の TSL lint / toInspector / tree-shake / compileAsync は、表現側では「shader内部を見せても破綻しない設計」への圧として捉えるとよい。

If empty splat LOD levels merely fade alpha, they look broken. A separate gap mask synchronized with frustum and raycast lines reads as missing information that has not arrived yet. Object ID textures can drive not only selection outlines, but hue, line density, and stream age, merging diagnostics with art direction. USD loading becomes more legible when split into worker queue, command queue, data buffer, and materialization stages; long loads become time structure instead of progress bars. The r186/r187 TSL lint, toInspector, tree-shaking, and compileAsync work can be read as pressure toward shader systems whose internals can be shown without collapsing.
