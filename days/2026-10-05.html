注目事例と何が面白いかNotable examples and why they matter

今日いちばん面白いのは、three.jsの`getProgramVariant()`とrender cache keyの方向。これは通常、描画最適化の内部メモだが、variantが増える瞬間、cache hitする瞬間、rebuildされる瞬間を可視化すると、shader作品のテンションや場面転換に使える。`webgpu_tsl_occlusion_dither`は、隠れている/見えているをbinaryにせず、粒状の存在感として出せるのが良い。PlayCanvasのGSplat tree cutとBabylonのWebGPU Gaussian Point Splatting PRは、splatを単なる点群ではなく、距離、滞在、merge、uploadの状態譜面として扱う接続点になる。

The most interesting item today is the three.js direction around `getProgramVariant()` and render cache keys. These are usually internal optimization details, but if moments of variant growth, cache hits, and rebuilds become visible, they can drive tension and scene transitions in shader work. `webgpu_tsl_occlusion_dither` is useful because visibility becomes granular presence instead of a binary hidden/visible switch. PlayCanvas GSplat tree cuts and Babylon's WebGPU Gaussian Point Splatting PR connect splats to distance, residency, merge, and upload state rather than treating them as just point clouds.

表現・インタラクションのアイデアExpression and interaction ideas

短期: program variant / cache key / occlusion dither / reversed depthを4象限scopeにし、dragでmaterial pressure、clickでshader rebuild pulseを走らせる。派生: 圧縮テクスチャの端ブロック、GSplat tree cut、Gaussian splatの楕円をstream atlasにし、viewer位置でmerge範囲とupload pulseを変える。中長期: 10/4のreadback atlasに今日のvariant cacheとsplat streamを合流させ、`state texture`として毎フレームの内部状態を小さな画像に焼き、音やXR視線で読み出し方を変える。

Short term: place program variants, cache keys, occlusion dither, and reversed depth in a four-quadrant scope where dragging changes material pressure and clicking emits a shader-rebuild pulse. Derived idea: make compressed texture edge blocks, GSplat tree cuts, and Gaussian splat ellipses into a stream atlas where the viewer position changes merge ranges and upload pulses. Longer term: merge today's variant cache and splat stream into 10/4's readback atlas, bake per-frame internal state into a small state texture, and let audio or XR gaze change how it is read.

制作に使えそうな技術メモProduction notes

ログ化候補はthree.js側が `programVariantId/cacheKey/cacheHit/rebuildReason/occlusionSample/depthMode/uintIndexBytes/renderObjectGroup`、PlayCanvas側が `compressedBlockX/compressedBlockY/blockTailBytes/gsplatNodeId/treeCutDepth/settledLeaf/mergedDrawRange/reverseZEnabled`、Babylon側が `splatId/gaussianRadius/pointBudget/inspectorLitePanel/shaderCursorToken/smartFilterNode/materialExtension`。実装では、全部をUIテキストにせず、4から16px程度の低解像度state textureにして、各pixelをlaneとしてshaderで読むと作品化しやすい。

Candidate log fields are `programVariantId/cacheKey/cacheHit/rebuildReason/occlusionSample/depthMode/uintIndexBytes/renderObjectGroup` for three.js, `compressedBlockX/compressedBlockY/blockTailBytes/gsplatNodeId/treeCutDepth/settledLeaf/mergedDrawRange/reverseZEnabled` for PlayCanvas, and `splatId/gaussianRadius/pointBudget/inspectorLitePanel/shaderCursorToken/smartFilterNode/materialExtension` for Babylon. Instead of showing everything as UI text, encode the data into a 4-16 px low-resolution state texture and let the shader read each pixel as a lane.

サンプルデータの可能性と組み合わせ考察Possibilities for the sample data and combinations

今回の2本は、入力を `probeX/probeY/mode/pulse/materialPressure/viewerPosition`、状態を `programVariantId/cacheHit/rebuildPulse/occlusionDither/depthMode/uintIndexBand/blockTailBytes/treeCutDepth/settledLeaf/gaussianRadius/uploadPulse` として保存できる。音反応ではkickでrebuild pulse、hi-hatでdither threshold、bassでtree cut半径を動かす。WebXRでは左右eyeのvariant cacheを分け、controller velocityをGSplat merge範囲に流す。展示では、観客が近づくほどcache hit率が上がって滑らかになり、離れるほどcompressed tail glitchが増えるようにすると、最適化が見える演出になる。

The two samples can store inputs as `probeX/probeY/mode/pulse/materialPressure/viewerPosition` and state as `programVariantId/cacheHit/rebuildPulse/occlusionDither/depthMode/uintIndexBand/blockTailBytes/treeCutDepth/settledLeaf/gaussianRadius/uploadPulse`. For audio, kick can trigger rebuild pulses, hi-hats can drive the dither threshold, and bass can change the tree-cut radius. For WebXR, split variant cache state per eye and feed controller velocity into GSplat merge range. In installation use, visitors getting closer could increase cache hits and smoothness while distance increases compressed-tail glitches, making optimization visible.
