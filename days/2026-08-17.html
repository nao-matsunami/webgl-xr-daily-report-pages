表現・インタラクションのアイデアExpression and interaction idea

短期案は「Packed Beam Prefix Lattice」。画面を小さな pack cell に分け、各 cell の 4 lane を色、発光、梁の太さ、bin の高さに割り当てる。Beam Lattice は節点と梁のネットワークとして表示し、PrefixSum は下部の累積 bar と scan sweep として出す。1-4 キーで packed / beam / prefix / orbit を切り替え、drag で orbit、click / Space で pulse。中長期では実 3MF Beam Lattice を読み込み、GaussianSplatMesh の sort bin、PlayCanvas MSAA sample variance、Babylon camera preset を同じ lattice の属性にする。

The short-term idea is Packed Beam Prefix Lattice. Split the screen into compact pack cells and map each cell's four lanes to color, glow, beam thickness, and bin height. Beam Lattice appears as a node-and-beam network; PrefixSum becomes cumulative bars and a scan sweep. Keys 1-4 switch packed / beam / prefix / orbit, dragging controls orbit, and click / Space injects a pulse. Longer term, real 3MF Beam Lattice data, GaussianSplatMesh sort bins, PlayCanvas MSAA sample variance, and Babylon camera presets should become attributes on the same lattice.

制作に使えそうな技術メモProduction note

`4x8` pack/unpack は、4 つの 0-255 相当の値を 1 つの扱いやすい単位に寄せる考え方として使える。WebGL だけで試す場合も、`floor(value * 16.0) / 15.0` のような粗い量子化で「byte lane らしさ」は再現できる。Beam Lattice は mesh surface ではなく graph として考えると扱いやすく、node は pulse、edge は beam、edge weight は thickness / emission に割り当てられる。PrefixSum は histogram の累積なので、rendering の内部処理であると同時に、鑑賞者が選んだ密度や視点の履歴を bar / sweep / contour で見せる UI 以外の可視化にもなる。multi-touch rotate はスマホでの「両指で構造をひねる」演出に直結する。

`4x8` pack/unpack can be treated as a way to move four 0-255-like values as one convenient unit. Even in plain WebGL, coarse quantization such as `floor(value * 16.0) / 15.0` recreates the feel of byte lanes. Beam Lattice is easier to use as a graph than as a surface: nodes become pulses, edges become beams, and edge weights become thickness / emission. PrefixSum is cumulative histogram data, so it is both an internal rendering step and a non-UI visualization of density or viewpoint history through bars, sweeps, and contours. Multi-touch rotate directly suggests a mobile gesture where two fingers twist the structure.

サンプルデータの可能性と組み合わせ考察Possibilities for the sample data and combinations

このサンプルの mode、pointer、pulse、pack lane、beam node、prefix bar、orbit waypoint を時系列で保存すると、鑑賞者がどの圧縮状態や骨格を選んだかを再演できる。音と組み合わせるなら、低域を beam thickness、中域を prefix sweep、高域を pack lane sparkle に割り当てる。カメラや MediaPipe なら、手の開閉を pulse、両手の角度を lattice twist、顔向きを orbit waypoint にできる。WebXR では Beam Lattice の節点を空間内に置き、片目に packed state、もう片目に prefix / sort heat を重ねると、検査と鑑賞の中間になる。展示やブランド演出では、製品の工程ログ、ネットワーク経路、AI 推論 token、splat sort bin を梁構造として表示し、内部処理が積み上がる様子を見せられる。

If the sample's mode, pointer, pulse, pack lanes, beam nodes, prefix bars, and orbit waypoints are saved as time-series data, the visitor's chosen compressed state and skeleton can be replayed. With audio, lows can drive beam thickness, mids can drive prefix sweeps, and highs can drive pack-lane sparkle. With camera or MediaPipe, hand openness can control pulse, two-hand angle can twist the lattice, and face direction can choose orbit waypoints. In WebXR, Beam Lattice nodes can be placed in space, with one eye seeing packed state and the other seeing prefix / sort heat, sitting between inspection and performance.
