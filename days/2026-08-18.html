表現・インタラクションのアイデアExpression and interaction idea

短期案は「XR Uniform Frustum Depth Scope」。左右の eye matrix を水平の uniform lane として表示し、同期が外れると赤く漂い、クリックや Space で再同期 pulse が走る。FrustumArray は複数の視錐台を扇状の beam にし、scene depth debug は奥行き contour と fog、IBL correctness は上下反転する環境光 band として扱う。昨日の pack lane / beam / prefix から、今日は matrix lane / frustum beam / depth contour へ語彙を拡張する。

The short-term idea is XR Uniform Frustum Depth Scope. Left and right eye matrices appear as horizontal uniform lanes; when synchronization drifts they turn red and float, and click or Space sends a resync pulse. FrustumArray becomes fan-shaped frustum beams, scene-depth debug becomes depth contours and fog, and IBL correctness becomes vertically flipping lighting bands. Yesterday's pack lane / beam / prefix vocabulary expands into matrix lane / frustum beam / depth contour.

制作に使えそうな技術メモProduction note

WebXR の camera matrix array は、フレームごとに正しく GPU 側へ更新されて初めて両眼の描画が生きる。実装時は render object の再構築に頼らず、shared uniform buffer の dirty/update 経路を見える化するとデバッグにも演出にも使える。FrustumArray は複数 camera / cascade / multiview をひとつの配列として見せる発想と相性が良い。scene depth debug は postprocess の fog、outline、particle occlusion の元データになる。sRGB 指定と IBL Y-flip は色の正しさだけでなく、WebGL/WebGPU/Native 間で「同じ絵に戻る」確認用の visual checksum として使える。

WebXR camera matrix arrays only keep stereo rendering alive when GPU-side data is refreshed every frame. In implementation, visualizing the shared uniform-buffer dirty/update path, instead of relying on full render-object rebuilds, helps both debugging and expression. FrustumArray maps well to showing multiple cameras, cascades, or multiview frusta as one array. Scene-depth debug feeds fog, outlines, and particle occlusion. sRGB flags and IBL Y-flip are not only about color correctness; they can act as visual checksums that confirm WebGL, WebGPU, and Native are converging on the same image.

サンプルデータの可能性と組み合わせ考察Possibilities for the sample data and combinations

このサンプルの mode、pointer、pulse、matrix lane drift、frustum fan、depth contour、IBL band を時系列で保存すると、鑑賞者がどの同期状態を見ていたかを再演できる。音と組み合わせるなら、低域を depth fog、中域を frustum spread、高域を uniform resync sparkle に割り当てる。カメラや MediaPipe なら、顔向きを matrix lane、手の角度を frustum fan、手の開閉を resync pulse にできる。WebXR では片目に matrix freshness、もう片目に depth/IBL checksum を重ねると、デバッグ HUD と舞台照明の中間になる。展示やブランド演出では、配信遅延、AI 推論 step、マルチカメラ撮影、物流/都市データの同期状態を、この lane / fan / contour / band の構造で見せられる。

If the sample's mode, pointer, pulse, matrix-lane drift, frustum fan, depth contour, and IBL bands are stored over time, it can replay which synchronization state a visitor inspected. With audio, lows can drive depth fog, mids can drive frustum spread, and highs can trigger uniform-resync sparkle. With camera or MediaPipe, face direction can drive matrix lanes, hand angle can control frustum fans, and hand openness can fire resync pulses. In WebXR, showing matrix freshness in one eye and depth/IBL checksums in the other would sit between a debug HUD and stage lighting. For installations or brand work, streaming latency, AI inference steps, multi-camera shoots, or logistics/city-data synchronization can be shown with this lane / fan / contour / band structure.
