注目事例と何が面白いかNotable examples and why they matter

今日いちばん効くのは、Conference記事内の HTML in Canvas / THREE.HTMLTexture の話。9/15のFigma内3Dでは「デザインツール内に3Dを置く」だったが、今日は逆に「DOM的なUIを3D textureとして扱う」方向にできる。TAA input登録やTSL Inspector previewは、UIが単なるoverlayではなくrenderer状態を説明するtextureになると活きる。Babylonのcoarse-first splat streaming / local-space cullingは、重いradiance fieldやsplatを最初から完成形として出すのではなく、粗い到着、局所cull、詳細化を体験の時間軸にできる点が面白い。RootMotionは、動きの抽出をshader inputへ入れると、キャラクターの移動、足跡、camera staging、streaming priorityを同じ地図へ載せられる。

The strongest reference today is the Conference article's HTML in Canvas / THREE.HTMLTexture thread. September 15 put 3D inside a design tool; today flips the direction by treating DOM-like UI as a 3D texture. TAA input registration and TSL Inspector previews become more useful when UI is not just an overlay but a texture explaining renderer state. Babylon's coarse-first splat streaming and local-space culling are interesting because heavy radiance fields or splats do not need to appear finished at once; coarse arrival, local culling, and refinement can become the timeline of the experience. RootMotion becomes a shader input for placing character movement, footsteps, camera staging, and streaming priority on one map.

制作に使えそうな技術メモProduction notes

HTMLTexture系を試す時は、UIを最初から完全なDOM同期にしないほうが扱いやすい。まずは Canvas2D snapshots、dirty rect、texture upload budget、pointer hit region、TAA reset reason を小さなstate schemaにする。three.js PR #34565 の方向からは inputRegisteredBeforeConsumer、historyValid、consumerFrame、resetPulse のような値が作れる。TextureNode filter/type changeは textureVersion、filterMode、sampleType、needsRebuild へ落とせる。Babylon 9.26.1系は objectId、textureLane、tileFade、particleSize、usdMaterialReady に加え、coarseLevel、localCullMask、rootTravel、rootTurn を足すと、asset streamとmotion streamを1枚のRGBA textureへ詰めやすい。

For HTMLTexture-style work, avoid full DOM synchronization at first. Start with Canvas2D snapshots, dirty rectangles, texture-upload budget, pointer hit regions, and TAA reset reasons as a small state schema. From the direction of three.js PR #34565, useful values are inputRegisteredBeforeConsumer, historyValid, consumerFrame, and resetPulse. TextureNode filter / type changes can map to textureVersion, filterMode, sampleType, and needsRebuild. For Babylon 9.26.1 work, add coarseLevel, localCullMask, rootTravel, and rootTurn to yesterday's objectId, textureLane, tileFade, particleSize, and usdMaterialReady so asset streams and motion streams can fit into one RGBA texture.
