注目事例と何が面白いかNotable examples and why they matter

注目事例は、PlayCanvas の splat formats docs と SuperSplat v2.32.x の export 強化を、SIGGRAPH の Gaussian Splatting virtual production 事例、ULTRA の single-pass GLSL surface 群と並べて見ることです。PlayCanvas docs は PLY、SOG、Streamed SOG、GLB、SPZ を用途、サイズ、品質、速度で切り分けています。これは単なる保存形式表ではなく、作品内で『どの部分が即時表示で、どこが標準 interchange で、どこが高精細 export 待ちか』を可視化する設計語彙になります。SIGGRAPH の事例は splat を撮影・演出の空間として使う方向、ULTRA は画像なし単体 shader surface を触れる光として成立させる方向で、両者を組み合わせると、splat scene の format/loading/export 状態そのものを触れる照明・粒子・ラベルとして表現できます。

The notable connection is to read PlayCanvas splat format docs and SuperSplat v2.32.x export improvements alongside the SIGGRAPH Gaussian Splatting virtual production case and ULTRA's single-pass GLSL surfaces. PlayCanvas separates PLY, SOG, Streamed SOG, GLB, and SPZ by use case, size, quality, and speed. That is more than a file-format table; it becomes a visual vocabulary for showing which parts of a work are immediate runtime delivery, which are standards interchange, and which are waiting on high-resolution export. The SIGGRAPH case treats splats as production space, while ULTRA treats shader surfaces as touchable light. Together they suggest making format/loading/export state itself visible as lighting, particles, and labels inside the splat scene.

表現・インタラクションのアイデアExpression and interaction ideas

今日の中心案は「format pressure を見せる splat scope」です。画面を GLB/KHR、SOG stream、SPZ compressed、HTML/MSDF labels の 4 レーンに分け、ポインタを inspection lens、長押しを relighting coverage、F を fisheye stress、Space を 8K/export pressure pulse にします。GLB/KHR レーンは標準 interchange と AA mismatch、SOG レーンは chunk stream risk、SPZ レーンは圧縮で細部が軽くなるが export には強い状態、HTML/MSDF レーンは小さい文字の coverage ramp と HTMLTexture 注釈面として読む。短期では疑似データの shader 表現で十分です。中長期では PlayCanvas の actual format / currentRenderer / chunk load / relighting coverage alpha / export queue を uniform または texture に流し込みます。

Today's core idea is a splat scope that visualizes format pressure. Split the screen into four lanes: GLB/KHR, SOG stream, SPZ compressed, and HTML/MSDF labels. Pointer acts as an inspection lens, holding reveals relighting coverage, F toggles fisheye stress, and Space triggers an 8K/export pressure pulse. The GLB/KHR lane reads as standards interchange plus AA mismatch; SOG reads as chunk-stream risk; SPZ reads as compressed detail tradeoff with strong delivery; HTML/MSDF reads as tiny text coverage ramp and HTMLTexture annotation surfaces. Short term, pseudo data in a shader is enough. Mid/long term, feed actual PlayCanvas format, currentRenderer, chunk load, relighting coverage alpha, and export queue into uniforms or a texture.

制作に使えそうな技術メモProduction notes

PlayCanvas v2.21.0 の KHR_gaussian_splatting と SPZ 対応により、runtime loader は format ごとの分岐を隠しやすくなりますが、表現側ではむしろ format を消さないほうが面白いです。GLB は標準化・他ツール連携、SOG は runtime delivery、Streamed SOG は超大規模 scene の視線依存、SPZ は mobile/share という役割を shader channel にできます。MSDF coverage ramp 修正は label の最小サイズ検証に効きます。Babylon の resize leak 修正は DPR 変更、orientation 変更、8K capture の stress test とセットで見るべきです。three.js HTMLTexture は canvas 内に HTML 由来の注釈を入れ、fragment shader で distortion / occlusion / relighting と混ぜる候補です。

PlayCanvas v2.21.0 KHR_gaussian_splatting and SPZ support make it easier for runtime loaders to hide format-specific branches, but expression-wise it may be better not to hide format. GLB can mean standardization and tool interchange; SOG can mean runtime delivery; Streamed SOG can mean view-dependent very-large-scene loading; SPZ can mean mobile/share-friendly compression. The MSDF coverage-ramp fix matters for minimum label-size tests. Babylon's resize leak fix should be tested with DPR changes, orientation changes, and 8K capture. three.js HTMLTexture is a candidate for HTML-derived annotations that can be distorted, occluded, and relit in fragment shaders.

俯瞰メモBird's-eye memo

最近の傾向は、Gaussian Splat が『見た目の新奇性』から『交換・圧縮・streaming・export・照明の状態をどう扱うか』へ移っていることです。7/17-7/23 は retry budget、upload gesture、export resolution、format pressure。7/25 は relighting / fisheye / flashlight。今日 7/26 はそれを glTF/SPZ/SOG/HTML label の互換性と出力圧力へ広げました。組み合わせる価値が高いテーマは、format state を隠すローダーではなく、format state を触れる光・粒子・ラベルに変えること。育てる価値が高いのは、作品にも検証にも使える shader diagnostic layer です。

The recent trend is that Gaussian Splatting is moving from visual novelty to handling interchange, compression, streaming, export, and lighting state. 07-17 to 07-23 covered retry budget, upload gesture, export resolution, and format pressure. 07-25 covered relighting / fisheye / flashlight. Today, 07-26 expands that into glTF/SPZ/SOG/HTML-label compatibility and output pressure. The high-value combination is not a loader that hides format state, but an expressive layer that turns format state into touchable light, particles, and labels. The theme worth growing is a shader diagnostic layer useful both as artwork and as verification tooling.
