制作に使えそうな技術メモProduction notes

unlit splat への簡易照明は、まず postprocess の `color *= mix(dark, lit, mask)` で十分に検証できる。mask は円形だけだと UI 的なので、`dot(normalize(p - pointer), dir)` を混ぜて方向 cone にするとカメラ操作と結びつく。cutout は SDF box で `removed` と `rim` を分け、rim だけ HDR 風に加算すれば bloom 前提の見え方を作れる。Wave Grid 型の idle wave は、入力がない時間にも画面を維持するための低コストな state source。Babylon の side-effect registration 修正から見ると、実案件では loader/postprocess/audio の import 経路が bundler で落ちないかを小さい起動テストにするのがよい。

For quick lighting on unlit splats, a postprocess-style `color *= mix(dark, lit, mask)` is enough to validate the idea. A circular mask feels like UI, so mixing in `dot(normalize(p - pointer), dir)` creates a camera-linked cone. For cutouts, separate `removed` and `rim` with an SDF box, then add the rim as HDR-like color before bloom. Wave Grid-style idle waves are a low-cost state source that keeps the screen alive without input. In light of Babylon's side-effect registration fix, real projects should add small startup tests to ensure loaders, postprocesses, and audio modules are not removed by the bundler.

俯瞰メモBird's-eye memo

最近の傾向は、3DGS を「写真のような点群」から「編集可能な舞台」にする方向へ進んでいること。SOG streaming、cutout、relighting、MSDF、HTMLTexture、Web Audio は別々の話に見えるが、実際には場の状態を shader field に戻すための入力チャンネルとして揃ってきている。組み合わせ候補は、懐中電灯 mask + cut rim + idle wave + 音源方向 + HTMLTexture 注釈。育てる価値が高いテーマは「見た場所だけが明るくなり、触った場所だけが切れ、聞こえる場所だけが波打つ」探索型のWeb空間。短期はGLSL一枚で成立し、中長期では PlayCanvas/SuperSplat の実データへ差し替える。

The recent trend is moving 3DGS from photographic point clouds toward editable stages. SOG streaming, cutouts, relighting, MSDF, HTMLTexture, and Web Audio look separate, but they are becoming input channels that feed scene state back into shader fields. Promising combinations are flashlight masks, cut rims, idle waves, sound direction, and HTMLTexture annotations. The theme worth growing is an exploratory web space where viewed areas brighten, touched areas cut open, and audible areas ripple. Short term, a single GLSL pass is enough; longer term, replace synthetic inputs with real PlayCanvas/SuperSplat data.
