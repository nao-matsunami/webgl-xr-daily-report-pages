注目事例と何が面白いかNotable examples and why they matter

Depth が面白いのは、WebGL表現を最終ページだけではなくデザインツールの作業面へ入れている点。操作中に品質を落とし、最終配置では影やedgeを戻す設計は、rendererの状態変化そのものをUIのリズムにできる。さらにheroでは完全live 3Dを諦め、制御済みのframe sequenceとreal-time layerを混ぜている。これは「全部をリアルタイム化しない」ことがむしろ高品質なインタラクションになる例。Babylon の object ID geometry textures / stream diagnostics は、選択・ロード・診断を色の層として扱える。PlayCanvas のcascade / material map修正は、9/14の監査面を現実のengine logへ近づける。

Depth is interesting because WebGL is moved into the working surface of a design tool, not just the final page. Lowering quality during interaction and restoring shadows / edges for final placement turns renderer-state changes into UI rhythm. Its hero also abandons fully live 3D in favor of a controlled frame sequence mixed with real-time layers; not rendering everything live becomes the route to higher-quality interaction. Babylon's object ID geometry textures and stream diagnostics can be treated as color layers for selection, loading, and inspection. PlayCanvas' cascade and material-map fixes keep September 14's audit surface close to real engine logs.

制作に使えそうな技術メモProduction notes

Depth型の体験では、操作中preview、poster、media sequence、final stillを同じ品質では扱わないのが肝。shader側では qualityBudget、sequenceFrame、materialSweep、placementPulse をuniform化すると扱いやすい。three.js r186文脈では compileAsync / readback / resetState / dispose / native splat / SunLight cascade を、品質切替のeventとして記録できる。Babylon object ID geometry textures は選択色だけでなく、tile residency、USD material arrival、stream diagnostics と同じRGBA state textureへ入れると展開しやすい。PlayCanvas StandardMaterial map iterationは、own / prototype / missing map を別laneにすることで、制作ツールの「見落とし検出」を演出へ変換できる。

Depth-like experiences should not treat interaction preview, poster, media sequence, and final still as the same quality tier. On the shader side, qualityBudget, sequenceFrame, materialSweep, and placementPulse are useful uniforms. In the three.js r186 context, compileAsync, readback, resetState, dispose, native splats, and SunLight cascades can be logged as quality-switch events. Babylon object ID geometry textures become more useful when packed with tile residency, USD material arrival, and stream diagnostics into one RGBA state texture. PlayCanvas StandardMaterial map iteration can split own / prototype / missing maps into lanes, turning missed-asset detection inside a production tool into expression.
