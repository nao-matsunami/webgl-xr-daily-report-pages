注目事例と何が面白いかNotable examples and why they matter

ZERO は「丸を描く」という軽い入力を gate として使い、その中心を frost shader の seed にしている点が参考になる。前回の flashlight/cut pressure も、クリックだけでなく形状認識やジェスチャ成立をトリガーにできる。Cerebrium は TSL/WebGPU から WebGLRenderer + onBeforeCompile + GPGPU ping-pong へ戻した実務判断が重要で、視覚差分を bloom/fog/material 色の再調整問題として扱っている。PlayCanvas の GSplat/Firefox WebGPU 修正は、同じ splat 表現でも backend/browser ごとにソートや resolve の見え方が変わる可能性を示す。これらを合わせると、互換性チェック自体を表現レイヤーに変換できる。

ZERO is useful because a simple draw-a-circle gesture becomes a gate, and its centroid seeds the frost shader. Yesterday's flashlight and cut pressure could be triggered by recognized shapes, not only clicks. Cerebrium's move from TSL/WebGPU back to WebGLRenderer plus onBeforeCompile and ping-pong GPGPU is important because it treats visual mismatch as bloom, fog, and material-color recalibration. The PlayCanvas GSplat Firefox WebGPU fix shows that the same splat expression can differ by backend and browser. Together, these suggest turning compatibility checks themselves into an expressive layer.

表現・インタラクションのアイデアExpression and interaction ideas

短期案は「Resolve Prism」。画面を4つの見えない検証レーンに分け、blend equation、XR MSAA resolve、3D texture slice readback、GSplat sort heat を色で重ねる。ポインタは inspection lens、ドラッグ方向は wake、押下は compatibility pressure として使う。前回の懐中電灯は「照らす場所」を決める入力だったが、今日は「どの互換性問題を見るか」を決める入力に変える。中長期では、実際の renderer/backend 切替、pixel diff、frame timing、GPU memory を同じ色チャンネルに流し、作品でありデバッグHUDでもあるビューに育てる。

The short-term idea is Resolve Prism. Split the screen into four invisible diagnostic lanes and layer blend equation, XR MSAA resolve, 3D texture slice readback, and GSplat sort heat with color. The pointer is an inspection lens, drag direction is wake, and press state is compatibility pressure. Yesterday's flashlight selected where to illuminate; today the same input selects which compatibility problem to inspect. Longer term, feed real renderer/backend switches, pixel diffs, frame timing, and GPU memory into the same color channels so the piece becomes both artwork and debugging HUD.

制作に使えそうな技術メモProduction notes

WebGPU/WebGL 併用時は、シェーダーの正しさだけでなく、blend equation、MSAA resolve、texture readback、MRT clear の差分を個別に小さく検証するのがよい。PlayCanvas の MRT 系 PR は、G-buffer 的な本格用途だけでなく、色・ID・heat・coverage を別 attachment へ吐く診断表現に使える。three.js の r185/r186 周辺では HTMLTexture、TSL、WebGLBackend の差分を「同じ入力から同じ絵になるか」で見る必要がある。Babylon.js の side-effect registration は、import したつもりの loader や postprocess が実行時に登録されているかを smoke test に入れるべきという合図。制作面では、ZERO の virtual scroll のように単一の正規化値で shader、DOM、音、遷移を駆動すると管理しやすい。

When mixing WebGPU and WebGL, validate not only shader correctness but also blend equations, MSAA resolve, texture readback, and MRT clears in small isolated tests. PlayCanvas MRT work is useful not only for G-buffer pipelines, but also for diagnostic expression that writes color, ID, heat, and coverage to separate attachments. Around three.js r185/r186, HTMLTexture, TSL, and WebGLBackend differences should be judged by whether the same input produces the same image. Babylon's side-effect registration fix is a reminder to smoke test whether imported loaders and postprocesses are actually registered at runtime. For production structure, ZERO's virtual scroll pattern suggests driving shader, DOM, audio, and transitions from one normalized value.

俯瞰メモBird's-eye memo

最近の流れは、3DGS/HTMLTexture/MSDF/TSL/WebGPU を単独機能として追う段階から、backend 差分や初期化時間まで含めて体験設計する段階へ移っている。Cerebrium は WebGPU/TSL の表現力と起動時間のトレードオフ、ZERO は入力 gate と shader seed の接続、PlayCanvas は GSplat の実行環境差分、three.js は r186 前の backend 整合性を示している。組み合わせるなら、前回の flashlight で見る領域を絞り、今日の prism で互換性チャンネルを重ね、ZERO 型 gesture gate で状態遷移させるのが筋がよい。育てる価値が高いテーマは「デバッグ情報がそのまま世界の質感になるWebGL空間」。

The recent shift is from tracking 3DGS, HTMLTexture, MSDF, TSL, and WebGPU as separate features toward designing experiences that include backend differences and startup time. Cerebrium shows the tradeoff between WebGPU/TSL expressiveness and startup cost, ZERO connects input gates to shader seeds, PlayCanvas highlights GSplat runtime differences, and three.js shows backend consistency work before r186. A promising combination is to narrow the viewed region with yesterday's flashlight, overlay compatibility channels with today's prism, and change state with ZERO-style gesture gates. The theme worth growing is a WebGL space where debug information becomes the surface texture of the world.
