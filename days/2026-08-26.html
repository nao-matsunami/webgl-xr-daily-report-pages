制作に使えそうな技術メモProduction notes

NTC/fp16系は、実装前に storage buffer の half 対応、fallback時のfp32化、decoder cost、mip/latent grid のcache局所性を分けて測る。PlayCanvas #9221 のような custom resolve は、hardware resolve が苦手なinteger/r32floatや、透明・edge・particleでsampleごとの履歴が必要な時に効く。#9226 の depthResolveMode は soft particles や depth fog の端ノイズを減らす実務的なノブで、SAMPLE0は比較用、MINは安定優先、MAXは背面寄りの効果確認に使える。Babylon #18830 の shared shader loading state は、material cloneが増える展示/EC/Configuratorで初回欠落を避けるための運用メモとして重要。#18836 の readiness regression は one-shot render や thumbnail生成で特に効くため、renderCount:1系の検証を日報サンプルにも残したい。

For NTC/fp16 work, measure storage-buffer half support, fp32 fallback, decoder cost, and mip/latent-grid cache locality separately before implementation. Custom resolves like PlayCanvas #9221 matter for integer/r32float formats that hardware cannot resolve, and for transparency, edges, and particles that need per-sample history. #9226 depthResolveMode is a practical knob for reducing soft-particle and depth-fog edge noise: SAMPLE0 for comparison, MIN for stability, MAX for rear-biased effects. Babylon #18830 shared shader loading state is important for exhibitions, ecommerce, and configurators with many cloned materials. #18836 readiness regression matters for one-shot rendering and thumbnail generation, so renderCount:1-style checks should appear in future samples.

サンプルデータの可能性と組み合わせ考察Possibilities for the sample data and combinations

今日の2本は、色や形そのものよりも、内部状態のログを入力にしたときに伸びる。NTC sample は latent cell値、量子化step、decoder cost、sample mask bit、depth resolve mode をCSV/JSONにできる。音反応なら低域をcompression pulse、中域をsample mask、高域をfp16 band sparkleに割り当てる。カメラやMediaPipeなら手の位置をdecoder light、手の開閉をresolve modeへ接続する。Splat readiness sample は sort完了時刻、表示splat数、LOD drop率、media layer transform、IES intensityを入力にできる。WebXRでは、quad layerを近景、cylinder layerを周辺情報、equirect layerを環境記憶として分けると、ロード待ちも演出になる。

Both samples grow best when internal-state logs become inputs rather than when only colors and shapes are changed. The NTC sample can accept latent cell values, quantization steps, decoder cost, sample mask bits, and depth resolve modes as CSV/JSON. For audio, map bass to compression pulse, mids to sample masks, and highs to fp16 band sparkle. With camera or MediaPipe, map hand position to decoder light and hand open/close to resolve mode. The splat readiness sample can take sort completion time, visible splat count, LOD drop ratio, media layer transforms, and IES intensity. In WebXR, use quad layers for near media, cylinder layers for peripheral information, and equirect layers for environmental memory so loading waits become staging.
